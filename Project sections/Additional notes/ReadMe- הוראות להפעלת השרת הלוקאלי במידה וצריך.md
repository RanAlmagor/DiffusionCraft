# 🖼️ DefusionCraft Local Worker – Stable Diffusion EXE

This is a standalone executable (`.exe`) that runs the local DefusionCraft worker. It uses Stable Diffusion to generate AI images based on user prompts.

---

## ⏳ Before You Begin

### ✅ Step 1: Run the EXE

- Launch the `worker.exe` file.
- You might see a security warning — approve it if needed.
- The local server will start initializing in the background.

### ⏳ Step 2: Wait for Model Loading

- **Please wait approximately 3 minutes** for the model to fully load.
- During this time, you’ll see loading messages from PyTorch and the `diffusers` library.

### 🔐 Step 3: Enter Hugging Face Token

- Once prompted, you must enter a **Hugging Face Token** to download the model.

## ℹ️ Requirements

- Internet connection (only needed on first launch to download the model).
- No Python installation required — all dependencies are bundled inside the EXE.
- The model is cached automatically after the first run.
